# backtest — 매수스카우트 신호 성과 원장

## 목적

`scores.json` 의 git 이력(2026-06-22~, 하루 여러 번 커밋)을 일별 신호 스냅샷으로 보고,
각 신호(시장 x `type_v3_0` x `gate_v3_0`)가 이후 5/10/20거래일 동안 지수·같은 날 유니버스 대비
얼마나 초과수익을 냈는지 재현 가능하게 집계합니다. 특히 engine.py v3.1 의 `GATE_PARAMS` 변경
(미국 A 60→70, 미국 B 70→65·손절폭 10→15%)이 실제로 도움이 됐는지 리플레이로 검증합니다.

- engine.py 를 import 하지 않습니다. 게이트 판정(`gate_ab`)은 `ledger.py` 안에 독립 구현했고,
  모든 정본 행에서 기록된 `gate_v3_0` 와 일치하는지 리포트 3절에서 확인합니다.
- 저장소의 다른 파일은 읽기만 합니다. git 은 `log`/`show` 만 씁니다.
- 결과(`out/`)와 캐시(`cache/`)는 `.gitignore` 로 커밋되지 않습니다. 성과 수치를 공개 저장소에 올리지 마십시오.

## 실행

```
python backtest/ledger.py            # 캐시 사용(없는 심볼만 다운로드)
python backtest/ledger.py --refresh  # 가격을 Yahoo 에서 다시 받음
```

- Windows 콘솔에서는 `PYTHONIOENCODING=utf-8` 을 권장합니다(진행 로그가 한글).
- 의존성: Python 3.10+, `numpy`, `requests`(다운로드 시), `exchange_calendars`(+ `pandas`, 세션 판정에만).
  없으면 `pip install --user numpy requests exchange_calendars`.
- 첫 실행은 git show 436회 + 가격 125개 다운로드로 2~3분, 이후 실행은 캐시만 써서 약 20초입니다
  (CI 진단 시뮬레이션 포함).

산출물(`backtest/out/`):

| 파일 | 내용 |
|---|---|
| `report.md` | 한국어 리포트. 결론 요약·주의사항, 커버리지(가격 캐시 감사·history_gap 포함), docstring 주장 재현, v3.1 리플레이, 사전등록 판정, 셀 성과(3개 기간), 한국 ok, 안정성 KPI, 후보 규칙, 익일 시가판, CI 방법 진단, 입력·출력 해시 |
| `signals.csv` | 정본 신호 행 원장. 신호일(매칭), 스냅샷 sha·버전, 라벨, 재판정 게이트(`g30`/`g31`/`g_own`), 전진수익 `r5/r10/r20`, 지수 수익 `ri*`(한국 ^KS11, 미국 ^GSPC), 나스닥 `ra*`(미국), 초과수익 `ex_idx*`/`ex_uni*`/`ex_ndx*`, 익일 시가 진입 `ro20`·비용차감 `o20_net`·지수 대비 `ex_idx_o20_net`, 정보 시점 구분 `info`(is/gray/oos), 결정 시점 절단 수익 `r20d`·`ex_*20d`, 표시 플래그 `chg_ok`·`split_alt`·`lt_date`·`lt_match` |
| `cells.csv` | 셀(시장 x 유형 x 게이트, `*` 는 전체) x 기간(`all`/`in`/`v31`) x 보유기간(5/10/20) x 벤치마크(`raw`/`idx`/`uni`/`ndx`/`idx_open_net`) 통계. `eps`(겹치지 않는 h일 보유)·`runs`(연속 구간), 블록 부트(`boot_*`), NW(`nw_*`, `nw_cv` 는 고정-b 임계값), EWC(`ewc_*`) |

캐시(`backtest/cache/`): `snapshots/{sha}.json.gz`(git show 결과), `prices/{심볼}.json`(Yahoo 응답 원문 + 다운로드 시각).

## 방법

### 정본 스냅샷 규칙

1. `git log --format="%H %ct" -- scores.json` 의 모든 커밋을 읽습니다. v3.0 이전(`type_v3_0` 없음) 스냅샷은 제외합니다.
2. 데이터 시각은 `as_of`(KST)를 씁니다. `as_of` 가 커밋 시각과 -15분~+6시간 범위에서 맞지 않으면 커밋 시각을 씁니다.
3. 시장별로 아래 스냅샷을 제외합니다.
   - 장중 스냅샷: exchange_calendars(XKRX/XNYS) 세션의 개장~마감+60분 안에 찍힌 것(그 시장만 제외).
     지수 봉이 없는 날(예: 2026-07-17 제헌절)은 휴장으로 보정합니다.
   - `stale_guard[시장]` 이 있는 것.
   - 0값 봉 오염: `stop_loss_pct >= 50` 인 행이 20% 넘는 것(2026-09-28 사고).
   - 엔진 이력 결함(history_gap): 행 `chg_pct` 가 가격 캐시의 (매칭일 종가 / 직전 거래일 종가 - 1)과 0.15%p 넘게
     다른 행이 20% 넘는 것. 엔진이 봉 하나가 빠진 이력으로 라벨을 계산한 경우입니다(예: 미국 09-23 정본 1780cd1).
     20% 이하인 스냅샷의 불일치 행은 `chg_ok=0` 으로 표시만 합니다.
4. 행 단위로 제외합니다: 한국에서 `^\d{6}\.(KS|KQ)$` 가 아닌 티커(07-29~31 ADR 혼입), close 없음, 가격 시계열 없음.
5. 가격 캐시 감사: 1~3을 통과한 스냅샷의 (티커, `last_ts` 날짜, close) 관측을 캐시 종가와 대조합니다. 0.15% 넘게
   어긋나는 관측일이 연속 2일 이상이고 비율이 일정(편차 0.05% 이내)하면 '캐시 계단'(Yahoo 국소 오염)으로 보고
   그 구간 캐시 종가·시가에 비율을 곱해 보정합니다(예: 207940.KS 09-22~10-01 x1.00679). 하루짜리 불일치는
   보정하지 않습니다. `last_ts` 는 2026-08-01 이후에만 있어 그 이전 구간은 감사할 수 없습니다.
6. 신호일 매칭: 스냅샷 날짜로 추정하지 않고, 데이터 시각 이전에 완결된 최근 세션부터 5거래일을 거슬러 올라가며
   Yahoo 종가와 행 `close` 가 상대오차 0.15% 이내로 일치하는 첫 거래일을 신호일로 합니다. 분할은 후보일마다
   '데이터 시각 이후 분할 누적' 배수를 먼저, 이어서 후보일 이후 분할들의 다른 누적곱(그리고 1)을 시도합니다
   (대체 배수로 맞으면 `split_alt=1`). 실패한 행은 제외하고 개수를 리포트에 적습니다. 스냅샷의 신호일은 행 신호일의
   최빈값이고, 최빈값과 다른 행(오매칭 포함)은 제외하고 티커를 적습니다.
7. (시장, 신호 거래일)마다 데이터 시각이 가장 이른 유효 스냅샷 1개를 정본으로 씁니다(사용자가 장 마감 뒤 처음 본 값).
   같은 (시장, 거래일)의 나중 커밋은 무시합니다. 민감도 확인용으로 '마지막 커밋' 정본 결과도 2절에 함께 적습니다.
8. 우선주 009155.KS·006405.KS 는 유니버스에 그대로 두고 `preferred=1` 로 표시합니다.

### 수익률

- 신호일 종가(Yahoo, 분할조정) 진입 → +5/+10/+20 거래일 종가. 거래일은 시장 지수 봉 날짜입니다.
  종목 봉이 없는 날은 직전 종가를 씁니다(거래정지 대비).
- 보조: 익일 시가 진입 → +20일 종가, 비용(한국 0.25%·미국 0.05%, 왕복 1회) 차감.
- 초과수익: 시장 지수(한국 ^KS11, 미국 ^GSPC, 미국은 ^IXIC 도 보조), 같은 정본 스냅샷 유니버스 평균.
- 유니버스에서 빠진 종목도 가격을 따로 받으므로 생존편향이 없습니다.
- 가격수익률입니다(배당 제외). 지수도 가격지수입니다.
- 가격 URL 은 `.../v8/finance/chart/{sym}?range=2y&interval=1d` 에 분할 역조정용으로 `&events=div%2Csplit` 을 붙였습니다.
  다운로드 시점에 끝나지 않은 세션의 봉은 버립니다.

### 정보 시점 구분 (v3.1 결정 기준)

v3.1 결정 커밋 `fd9e6c6`(2026-08-30 15:52 UTC) 시점의 마지막 완결 세션(두 시장 모두 2026-08-28)을 기준으로 나눕니다.

- IS: 결정 시 20일 수익이 이미 완결된 신호(결정 전에 결과까지 볼 수 있었음, 신호일 ~07-30/07-31).
- 회색: 결정 시 신호는 있었지만 20일 수익은 일부만 관측된 신호(~08-27).
- 엄격 OOS: 신호일 >= 08-28(수익 전부가 결정 뒤에 실현).
- 결정 후 실현 = 회색 + 엄격 OOS.

docstring 재현의 주 비교는 명목 창(07-01~08-21) ∩ IS 이고, '결정 시점 절단'(미완결 신호를 08-28 종가까지 자른 수익)과
'명목 창 현재값'(결정 뒤 성과 포함)을 나란히 적습니다. 리플레이·판정·후보 규칙의 구간도 이 구분을 씁니다.

### 통계

- 셀 = 시장 x `type_v3_0` x `gate_v3_0`(라벨은 당시 표시값). 행 수 n, 에피소드 수, 종목 수, 신호 거래일 수, 평균, 승률(지수 초과>0).
- 에피소드: 겹치지 않는 h일 보유 단위입니다. 같은 티커가 에피소드 시작일부터 h 정본 거래일 안에 다시 나오면 같은 보유로
  묶고, 그 뒤 첫 신호가 새 에피소드를 엽니다. 연속 정본 거래일 구간 수는 `runs` 로 따로 둡니다(라벨 안정성 KPI 는 이것을 씀).
- 90% CI 세 가지를 모두 표시합니다.
  1. 블록 부트스트랩: 정본 거래일 위치 위의 원형 이동블록 부트스트랩(블록 = h, 행이 없는 날은 0, seed 20261005, 2000회)의
     표준오차 x 고정-b 임계값(b = 블록/구간). 거래일 5일 미만이거나 구간이 2블록 미만이면 생략.
  2. NW: 거래일별 셀 평균 시계열의 Newey-West(Bartlett, lag = h-1) 표준오차 x Kiefer-Vogelsang 고정-b 임계값
     (cv = 1.6449 + 2.1859b + 0.3142b² - 0.3427b³, b = (lag+1)/T). 거래일 10일 미만이면 생략.
  3. EWC: 같은 시계열의 equal-weighted cosine 장기분산(B = 거래일 // 2h) + t_B 임계값. B < 1 이면 생략.
     겹치는 h일 수익의 독립 관측 수(약 T/h)에 맞춘 보수적 CI 입니다.
- 리포트 10절 CI 진단: 평균 0인 독립 계열과 20일 겹침 계열(MA(19)+잡음)로 각 방법의 실제 기각률을 시뮬레이션합니다.
  이전 버전의 거래일 iid 부트·NW z 임계값은 명목 10% 를 크게 넘고, 고정-b 는 독립 계열을 바로잡지만 겹침 계열에서는
  여전히 20~30% 입니다. EWC 는 겹침 계열에서도 명목에 가깝습니다.
- naive t(행을 독립으로 센 t)는 docstring 주장과 비교하기 위해서만 적습니다.
- 기간: 전체(v3.0~), 명목 근거 창(신호일 2026-07-01~08-21), v3.1 이후(2026-08-31~). 정보 시점 구간은 위 절.
- v3.1 리플레이: 모든 정본 A·B 행을 v3.0·v3.1 파라미터로 각각 다시 판정하고, 게이트가 달라지는 행만 모아
  정보 시점 구간별로 전진 초과수익을 냅니다.
- 라벨 안정성 KPI: 일일 (유형, 게이트) 변경 종목 수 중앙값, ok 연속 구간 길이 분포와 1일 소멸 비율,
  같은 (티커, 신호일, close)인데 total 이 다른 키 수.

## 사전등록 채택 규칙

파라미터 변경(또는 되돌림)을 권고하려면 다음을 모두 충족해야 합니다. 주 지표는 유니버스 대비 20일 초과수익이고, 표본은 전 기간입니다.

- 에피소드(겹치지 않는 20일 보유) >= 30, 종목 >= 10, 서로 다른 신호 거래일 >= 60
- 90% CI 가 0을 포함하지 않음 — 블록 부트스트랩, NW 고정-b, EWC 세 가지 모두(평균과 같은 쪽)
- 표본 전반/후반(신호 거래일 중앙값 기준) 평균의 부호가 전체와 같음

하나라도 미달이면 결론은 '근거 부족 — 현행 유지·관찰 지속'(insufficient)입니다. 기본값은 변경 없음입니다.
EWC 조건은 원래 규칙의 'CI 가 0을 포함하지 않음'을 실제 포함률이 90% 에 가까운 CI 로 지키기 위한 보수적 해석입니다.

| 판정 대상 | 대상 행 | keep | revert/change |
|---|---|---|---|
| 미국 A 60→70 | v3.0 에서 ok, v3.1 에서 비ok 인 미국 A 행(강등 행) | 평균 < 0 | 평균 > 0 → 컷 60 으로 되돌림 |
| 미국 B 65/15 | v3.0 에서 비ok, v3.1 에서 ok 인 미국 B 행(승격 행) | 평균 > 0 | 평균 < 0 → 70/10% 로 되돌림 |
| 한국 60/70/10 | 한국 gate_v3_0=ok 행 | 평균 > 0 | 평균 < 0 → 파라미터 재검토 |

## 결정론

같은 입력(커밋 목록 + 가격 캐시)이면 `report.md`·`cells.csv`·`signals.csv` 바이트가 같습니다.
정렬 순서, 부트스트랩·시뮬레이션 seed, 출력 자리수를 고정했고 실행 시각을 출력하지 않습니다.
리포트 끝에 입력 해시(스캔 커밋 sha 목록, 정본 sha 목록, 가격 캐시)와 출력 해시를 적습니다.
확인 방법: 두 번 실행한 뒤 `sha256sum backtest/out/report.md backtest/out/cells.csv` 가 같은지 봅니다.

## 결과 해석 시 주의

- 표본이 작습니다. 2026-10 초 기준 정본 거래일은 시장당 65~66일이고, 20일 전진수익이 완결된 신호일은
  9월 초까지입니다. 거래일 >= 60 기준은 대부분의 셀에서 아직 충족되지 않습니다.
- 보유기간이 겹칩니다. 같은 종목이 며칠 연속 같은 라벨이면 20일 수익을 거의 공유하고, 연속 신호일의 20일 수익은
  19일씩 겹칩니다. 거래일 45일이면 독립 관측은 사실상 2개 남짓입니다. n 이 아니라 에피소드·거래일 수와 세 CI 를 보십시오.
- 단일 레짐입니다. 근거 표본 창(07~08월)에 코스피가 30% 넘게 급락했고, 그 뒤 반등했습니다. 지수 대비 수치는
